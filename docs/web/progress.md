## 3. 本番環境

- ホスティング：Vercel（Hobby）。関数の地域はシンガポール（`sin1`、`vercel.json`）。main へのマージで本番に自動デプロイ。
- DB：Neon（`ap-southeast-1`、接続は pooler 経由）。Vercel の Storage から作成し、`DATABASE_URL` は Production のみに設定。
- 認証：Google OAuth クライアント（同意画面は「テスト」のまま。ログインできるのはテストユーザーに追加したアカウントだけ）。
- 環境変数（Vercel の Production）：`DATABASE_URL`、`BETTER_AUTH_SECRET`（ローカルとは別の値）、`BETTER_AUTH_URL`、`GOOGLE_CLIENT_ID`、`GOOGLE_CLIENT_SECRET`。
- Preview 環境には環境変数を入れていないため、PR ごとのプレビューの画面はエラーになる（Google のリダイレクト URI が固定の URL しか登録できないため）。
- マイグレーションは手動。手元の `.env.production.local`（コミットしない）に本番の `DATABASE_URL` を置き、`node --env-file=.env.production.local ./node_modules/drizzle-kit/bin.cjs migrate` で当てる。スキーマを変える PR をマージしたら、デプロイの前後に実行する。
