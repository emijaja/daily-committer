# プロダクトと画面遷移

## コンセプト

- いろいろな習慣を登録し、日々記録するアプリ。
- 継続や活動量を **GitHub の草（コントリビューション）** のような表現で見せる。
- 草は「すべての習慣」と「習慣ごと」を切り替えて表示できる。
- 「習慣アプリなのにナマケモノ」——サボりたい気持ちを代弁してぼやくキャラが相棒。責めない、ゆるく続ける。

## 習慣のモデル

| 項目 | 内容 |
|---|---|
| 周期 | 毎日（日次）／毎週（週次・回数指定 例: 週3回）／毎月（月次・回数指定 例: 月8回） |
| 記録方式 | **チェックのみ（既定）**／量も記録 |
| 量の設定 | 単位（回・ページ・km など）、目標（任意。日次は1日の目標、週次は週の目標） |
| 量の入力のしかた | 習慣ごとの設定で切り替え：**合計を入力**（⑧-a）／**回ごとに足す**（⑧-b、合計で目標と比べる） |
| 状態 | 現在の習慣／過去の習慣（過去にしても記録と草は残る。戻せる） |
| 長期目標 | 扱わない（ひとまず保留） |

量の習慣の行の状態：未記録 / 途中（進み具合バー・「あと◯回」） / 目標達成 / 目標超え（「+15」など）/ 目標なし（量だけ記録）。

## ナビゲーション

- 下部タブ：**記録 ／ 振り返り ／ 習慣**
- 記録タブは上部タブで **今日（日次）／今週（週次）／今月（月次）** を別画面で記録。
- ホームに全体の草は出さない。草は「振り返り」で見る（**年間の草のみ**、月間の草は出さない）。

## 画面一覧

| ID | 画面 | 役割 |
|---|---|---|
| ①-a | 記録：今日 | 日次の習慣を記録。キャラがヘッダー下でぼやく |
| ①-b | 記録：今週 | 週次の習慣。曜日の四角に記録した日を表示 |
| ①-c | 記録：今月 | 月次の習慣。回数の進み具合をバーで表示 |
| ⑥-a | 振り返り | 年間の草（すべて／習慣ごと）、「達成していること」「もう少しで達成」 |
| ⑥-b | 日付を選ぶ | 草タップで開く月カレンダーのモーダル。選ぶだけ |
| ② | 記録の確認・修正 | 選んだ日の日次・その週の週次・その月の月次をまとめて修正 |
| ③ | 習慣の詳細 | 1つの習慣の連続記録・草・統計 |
| ④ | 習慣の一覧 | 現在／過去の切り替え。周期ごとにまとめる |
| ⑤-a | 習慣の追加 | 既定は「毎日」「チェックのみ」 |
| ⑤-b | 習慣の編集 | 周期・記録方式・単位・目標・入力のしかた・過去の習慣にする |
| ⑦ | 設定 | 記録画面の歯車から。ぼやき表示の切り替えなど |
| ⑧-a | 量の記録：合計を入力 | ボトムシート。±・まとめて足すチップ |
| ⑧-b | 量の記録：回ごとに足す | ボトムシート。テンキーで1回分を追加 |
| A1 | ログイン | O1 の次。Google ログインのみ・ログイン必須（スキップなし） |
| O1〜O5 | オンボーディング | ようこそ／タップで記録／草が生える／ぼやき＋通知許可／最初の習慣を選ぶ |
| E1〜E4 | 空の状態 | 習慣なし／週の習慣なし／振り返りの記録なし／記録開始前の日 |

## 画面遷移

```
[初回] O1 → A1（ログイン）→ O2 → O3 → O4（通知許可）→ O5（習慣を選ぶ）→ ①-a
        （O2 以降のスキップ → ①-a、習慣が0件なら E1。A1 はスキップ不可）
[ログイン済みで再訪] → ①-a（未ログインなら A1）

[記録タブ]  ①-a ⇄ ①-b ⇄ ①-c（上部タブ）
            ├ 行の□をタップ ……… その場で記録
            ├ 量の習慣の＋/行をタップ → ⑧-a または ⑧-b（習慣の設定で決まる）
            ├ ＋を長押し ………… 前回と同じ量で即記録（取り消しトースト）
            └ 歯車 → ⑦ 設定

[振り返りタブ] ⑥-a
            ├ 草をタップ → ⑥-b（その月を開いた状態）→ 日付を選ぶ → ②
            │                                     （開始前の日なら E4）
            └ 「達成していること」をタップ → ③

[習慣タブ]  ④ → 行をタップ → ③ → 編集 → ⑤-b
            └ ＋ → ⑤-a
```

- ⑥-a → ② は「草をタップ → 日付を選ぶ」の2タップで手早く遷移できること。
- ② からも量の習慣は ⑧ と同じシートで修正する。

## 振り返りの見せ方

- 達成率は出さない。代わりに文章で一覧表示する。
  - **達成していること**：例「読書を 27日 連続で続けています」「筋トレで 目標超え が 5日連続」「ランニングを 週3回ペース で継続中」
  - **もう少しで達成**：例「あと3日続けると、読書が 30日連続」「あと1回で、今週のランニング目標を達成」
- 目標超えも「達成していること」に出す。
