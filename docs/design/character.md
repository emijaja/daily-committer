# キャラクター（ナマケモノ）

## コンセプト

- モチーフは **ナマケモノ**。「習慣アプリなのにナマケモノ」。
- サボりたい気持ちを代弁して **ぼやく** アプリ共通の相棒（ユーザー自身のアバターではない）。Habitica を参考に、記録画面のヘッダー下に置く。
- 時間帯や記録の状況に応じてひとこと話す。**責めない**。ぼやきは怒りではなく「しょんぼり・あせあせ」で表す。
- 一人称は「ぼく」。口調はゆるく、少し自虐的（例：「ぼくは0個だけど」「ぼくには、とても無理…」）。
- 名前は未定。

## 形（採用：H1 ぶら下がり・簡略版）

- 平たい帯の枝にぶら下がり、右側で頭をこちらに傾ける姿。
- **顔と体は1本の輪郭線でつながっている**（左腕 → 体 → 頭のふくらみ → 右腕 を一筆）。頭の丸い輪郭は描かない。
- 線は「輪郭・腕の内側2本・指の短い線2本・枝」だけ。後ろ足や毛の描き込みはしない。
- 顔：豆形の顔の模様、点の目を包んで外側へ流れる目の帯、大きめの黒い鼻、鼻の下の短いにっこり。
- 線の太さはほぼ一定（約 2.6〜2.8 / 164px 幅）。塗りは白のみ。
- 背景に **蛍光イエローの丸**（幅の約 82%）を敷くのが基本。丸は使う側で敷く（コンポーネントには含めない）。

## 表情（コンポーネント `mascot/sloth` の `expression`）

| 値 | 名前 | 顔 | 付属 | 主な場面 |
|---|---|---|---|---|
| `normal` | ふつう | 点の目、にっこり口 | なし | 案内、習慣の追加 |
| `grumpy` | ぼやき（基本） | 細い横線の目、波線の口 | 汗のしずく | 記録画面の基本。未記録が残っているとき |
| `happy` | よろこび | ∩ の目、開いた口 | 喜びの線 | 全部できた、連続記録、達成 |
| `sleepy` | ねむい | ∪ の閉じた目、小さな口 | zzz | 夜、記録がない・空の状態、設定 |

## 使い方

| 場所 | 形 | サイズ目安 |
|---|---|---|
| 記録画面（①-a/b/c）のヘッダー下 | 全身＋黄色の丸、右に黒枠の吹き出し | 幅 140 |
| オンボーディング・空の状態 | 全身＋黄色の丸（大きく） | 幅 170〜300 |
| 振り返り・詳細・設定・追加などの一言 | 丸アイコン（顔まわりを切り抜き）＋吹き出し | 44px 円・黒枠 1.5px・黄色地 |

- 小さいアイコン（24〜36px）では線を細くする（拡大縮小で線幅も縮める）。
- 設定 ⑦ で「ぼやきを表示」「通知でもぼやく」を切り替えられる。

## セリフ例（現時点のデザインで使っているもの）

| 場面 | 表情 | セリフ |
|---|---|---|
| 今日・夜で未記録あり | grumpy | 早起きはまた明日かぁ…。でも読書と筋トレはえらい。 |
| 今週・残りあり | grumpy | ランニングあと1回…。週末にまとめてやる気でしょ。 |
| 今月・ペースが遅い | grumpy | ジム、まだ1回かぁ。月末に8回は無理だからね？ |
| 全部できた | happy | 3つともできた！ 今日はもう、ゆっくりしよ。 |
| 寝る時間・残りあり | sleepy | そろそろ寝る時間だよ…。記録はあと1つ。 |
| 振り返り（連続記録） | happy | 27日も続いてるの？ ぼくには無理…。 |
| 習慣の詳細 | happy | 読書の日は、ぼくも隣で寝てるだけ。 |
| 習慣の追加 | normal | 新しい習慣…？ がんばってね。ぼくは見てる。 |
| 設定 | sleepy | 設定はほどほどにね。ぼくはもう寝る…。 |
| 習慣がまだない | normal | ぶら下がってるだけの毎日も、わるくないけど…。まずは1つ、登録してみよう。 |
| 振り返りの記録がない | sleepy | まだ何もないね…。ぼくといっしょ。 |
| 最初の習慣を選ぶ | normal | 3つくらいがちょうどいいよ。ぼくは0個だけど。 |

吹き出しの下にはメタ情報（例：`21:04 ・ 今日の残り 1`）を小さく出す。

# キャラクター（狛犬）

## コンセプト

- モチーフは **狛犬**（見た目は沖縄のシーサーのイラストを参考にした）。アプリ名「Sanpai」（お参り）にちなむ。
- メモ（⑨、[I2 日々のメモ](../ideas/README.md#i2-日々のメモ)）の **聞き役**。記録・習慣は「ぼやく相棒」のナマケモノ、メモは「聞く相棒」の狛犬、と役割を分ける。
- 状態：キャラクターのデザインは採用（2026-11-23）。コードには未実装。
- **メモに関わる UI のキャラは狛犬**、それ以外（① 記録・⑥ 振り返り・オンボーディング・空の状態・設定など）はナマケモノのまま。⑥ 振り返りでも、習慣へのぼやき（例：連続記録）はナマケモノ。

## 形（採用：シーサー風・正面）

- 正面を向いてどっしり座る。**頭と体は1本の輪郭線でつながり、顔はその内側に描く**（ナマケモノと同じ作り）。
- 輪郭：左の前脚 → 頬から顎までの左右3つずつのふくらみ → 先の丸い大きな耳 → 頭の上 → 反対側の耳 → ふくらみ → 右の前脚、を一筆。
- 巻き毛：頬のふくらみの切れ目から内側へ巻き込む線（左右3つずつ）。顎の下に内向きの巻き毛2つ、前脚に1つずつ。
- 耳の内側に「く」の字の線。前脚の間に短い線2本。
- 顔：外側が上がった葉っぱ形の重いまぶた、その下に白い光を入れた半月の黒目、点2つの鼻。口は表情で変える。
- しっぽ：左から立ち上がる炎形（丸いふくらみ＋炎の先2つ＋内側の曲線1本）。
- 台座：ナマケモノの枝に当たる平たい帯。
- 大きさと線はナマケモノと同じ：164×140、線 2.8（顔・巻き毛は 2.4）、塗りは白のみ。背景の蛍光イエローの丸は使う側で敷く。

## 表情（コンポーネント `mascot/komainu` の `expression`）

| 値 | 名前 | 顔 | 付属 |
|---|---|---|---|
| `normal` | 吽（ふつう） | 重いまぶた＋半月の黒目、口なし | なし |
| `happy` | 阿（よろこび） | `normal` と同じ目、口を開けて牙を見せる | 横の短い線2本 |
| `sleepy` | ねむい | 重いまぶた＋閉じた目、口なし | zzz |

- ナマケモノの `grumpy`（ぼやき）に当たる表情はない（狛犬はぼやかない）。
- 不採用：閉じ目（∩）の `happy`、お題を出す専用の `ask`（口を開けた顔は `happy` にまとめた）。

## 使い方

| 場所 | 形 | サイズ目安 |
|---|---|---|
| ⑨ メモ：書く のヘッダー下 | 全身＋黄色の丸、右に黒枠の吹き出し（①-a のキャラ欄と同じ形） | 幅 140 |
| ⑨-b 書く（入力）・⑨-b2 書きかけ・⑨-d 閉じるとき・⑨-b の参考（過去の日付・日付を選ぶ） | 丸アイコン（頭全体を切り抜き）＋黒枠の吹き出し | 44px 円・黒枠 1.5px・黄色地 |

- お題を出す・問いかける場面は `happy`（阿：口を開ける）、聞いている・しまう場面は `normal`（吽）。
- 丸アイコンは耳まで入るよう頭全体を切り抜く（顔の中心は元の座標で x=88・y=58 あたり。全身の 0.47 倍で置く）。
- 吹き出しの下にはメタ情報（例：`21:04 ・ よかったこと あと1つ`）を小さく出す。
- セリフ例：「今日よかったこと、3つ教えて。（3つめ）」「11月18日は、どんないいことがあった？」「しまっておくね。ちゃんと聞いてたよ。」「12日つづけて、3つ書けてる！ えらい。」
