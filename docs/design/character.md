# キャラクター（ナマケモノ）

## コンセプト

- モチーフは **ナマケモノ**。「習慣アプリなのにナマケモノ」。
- サボりたい気持ちを代弁して **ぼやく** アプリ共通の相棒（ユーザー自身のアバターではない）。Habitica を参考に、記録画面のヘッダー下に置く。
- 時間帯や記録の状況に応じてひとこと話す。**責めない**。ぼやきは怒りではなく「しょんぼり・あせあせ」で表す。
- 一人称は「ぼく」。口調はゆるく、少し自虐的（例：「ぼくは0個だけど」「ぼくには、とても無理…」）。
- 名前は未定。

## 形（採用：H1 ぶら下がり・簡略版）

- 平たい帯の枝にぶら下がり、右側で頭をこちらに傾ける姿。
- **顔と体は1本の輪郭線でつながっている**（左腕 → 体 → 頭のふくらみ → 右腕 を一筆）。頭の丸い輪郭は描かない。
- 線は「輪郭・腕の内側2本・指の短い線2本・枝」だけ。後ろ足や毛の描き込みはしない。
- 顔：豆形の顔の模様、点の目を包んで外側へ流れる目の帯、大きめの黒い鼻、鼻の下の短いにっこり。
- 線の太さはほぼ一定（約 2.6〜2.8 / 164px 幅）。塗りは白のみ。
- 背景に **蛍光イエローの丸**（幅の約 82%）を敷くのが基本。丸は使う側で敷く（コンポーネントには含めない）。

## 表情（コンポーネント `mascot/sloth` の `expression`）

| 値 | 名前 | 顔 | 付属 | 主な場面 |
|---|---|---|---|---|
| `normal` | ふつう | 点の目、にっこり口 | なし | 案内、習慣の追加 |
| `grumpy` | ぼやき（基本） | 細い横線の目、波線の口 | 汗のしずく | 記録画面の基本。未記録が残っているとき |
| `happy` | よろこび | ∩ の目、開いた口 | 喜びの線 | 全部できた、連続記録、達成 |
| `sleepy` | ねむい | ∪ の閉じた目、小さな口 | zzz | 夜、記録がない・空の状態、設定 |

## 使い方

| 場所 | 形 | サイズ目安 |
|---|---|---|
| 記録画面（①-a/b/c）のヘッダー下 | 全身＋黄色の丸、右に黒枠の吹き出し | 幅 140 |
| オンボーディング・空の状態 | 全身＋黄色の丸（大きく） | 幅 170〜300 |
| 振り返り・詳細・設定・追加などの一言 | 丸アイコン（顔まわりを切り抜き）＋吹き出し | 44px 円・黒枠 1.5px・黄色地 |

- 小さいアイコン（24〜36px）では線を細くする（拡大縮小で線幅も縮める）。
- 設定 ⑦ で「ぼやきを表示」「通知でもぼやく」を切り替えられる。

## セリフ例（現時点のデザインで使っているもの）

| 場面 | 表情 | セリフ |
|---|---|---|
| 今日・夜で未記録あり | grumpy | 早起きはまた明日かぁ…。でも読書と筋トレはえらい。 |
| 今週・残りあり | grumpy | ランニングあと1回…。週末にまとめてやる気でしょ。 |
| 今月・ペースが遅い | grumpy | ジム、まだ1回かぁ。月末に8回は無理だからね？ |
| 全部できた | happy | 3つともできた！ 今日はもう、ゆっくりしよ。 |
| 寝る時間・残りあり | sleepy | そろそろ寝る時間だよ…。記録はあと1つ。 |
| 振り返り（連続記録） | happy | 27日も続いてるの？ ぼくには無理…。 |
| 習慣の詳細 | happy | 読書の日は、ぼくも隣で寝てるだけ。 |
| 習慣の追加 | normal | 新しい習慣…？ がんばってね。ぼくは見てる。 |
| 設定 | sleepy | 設定はほどほどにね。ぼくはもう寝る…。 |
| 習慣がまだない | normal | ぶら下がってるだけの毎日も、わるくないけど…。まずは1つ、登録してみよう。 |
| 振り返りの記録がない | sleepy | まだ何もないね…。ぼくといっしょ。 |
| 最初の習慣を選ぶ | normal | 3つくらいがちょうどいいよ。ぼくは0個だけど。 |

吹き出しの下にはメタ情報（例：`21:04 ・ 今日の残り 1`）を小さく出す。
