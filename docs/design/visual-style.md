# ビジュアルスタイル（採用：みんなの銀行風）

参考：みんなの銀行アプリ（App Store のスクリーンショット）。ロゴ・固有の意匠は使わず、雰囲気だけを取り入れる。
比較検討した他案（マネーフォワード／メルカリ／Notion／ANA／Duolingo／ソフィBe 風）は不採用。

## 原則

- **白地に黒**。ほぼモノクロ。線画のイラストと黒い枠線で構成する。
- 差し色は **蛍光イエロー（#FFF100）を一点だけ**。キャラの背景の丸、強調のマーカー、「今日」「次に押す所」の印に限定する。
- 見出しは **英字の大見出し（Inter Extra Bold）＋小さな日本語の副題**（例：`Today` / 今日の習慣を記録）。
- 角は基本 **四角（角丸 0）**。丸めるのはピル型のボタン・タグ、ボトムシートの上辺だけ。
- 影は使わない。区切りは黒い線で表す。

## 色

| トークン | 値 | 用途 |
|---|---|---|
| `black` | #000000 | 文字・線・枠・塗りの主役、下部タブの背景、主ボタン |
| `white` | #FFFFFF | 背景・カード |
| `yellow` | #FFF100 | 差し色（一点のみ） |
| `gray-100` | #F2F2F2 | 進み具合バーの地 |
| `gray-200` | #EEEEEE | 草レベル0 |
| `gray-300` | #BDBDBD | 草レベル1、無効・未来の日、補助の線 |
| `gray-500` | #6E6E6E | 草レベル2、補足テキスト |
| `gray-600` | #555555 | 説明文 |
| `tabbar-inactive` | #8A8A8A | 下部タブの非選択 |

草（ヒートマップ）の4段階：`#EEEEEE` → `#BDBDBD` → `#6E6E6E` → `#000000`（未来の日は #EEEEEE を 40%）。

## 文字

| 用途 | フォント | サイズ |
|---|---|---|
| 英字の大見出し | Inter Extra Bold、字間 -2% | 32（シート内は 24） |
| 大きな数字（2 / 3、27 日 など） | Inter Black、字間 -2% | 40〜54 |
| 行の量の数字 | Inter Extra Bold | 18 |
| 日本語の見出し・行の名前 | Noto Sans JP Bold | 13〜20 |
| 日本語の副題 | Noto Sans JP Bold | 10 |
| 本文・説明 | Noto Sans JP Medium | 12〜13（行間 155〜165%） |
| 補足 | Noto Sans JP Medium | 9〜10、gray-500 |
| タグ | Inter Extra Bold、字間 +4% | 9 |

## レイアウト

- 画面幅 375（iPhone）。左右の余白 20、要素間 14〜16。
- ステータスバー → 見出し → 本文 → 下部タブ の順。
- 下部タブ：**黒地**、アイコン＋ラベル、選択中は白・非選択は #8A8A8A。

## コンポーネント規則

| 部品 | 仕様 |
|---|---|
| リストの箱 | 黒枠 1.5px・角丸0。行の区切りは黒 1px。行の内側余白 14/12 |
| チェック | 30×30 の四角・黒枠 1.5px。完了＝黒塗り＋白のチェック。量の習慣は「＋」 |
| 曜日の四角（週次） | 36×28。記録した日＝黒塗り白文字、今日（または選択日）＝黄色＋太枠 2.5px、未来＝灰色 |
| 進み具合バー | 高さ 4（シートでは 6）、地 #F2F2F2、黒で塗る |
| タグ | ピル型・黒枠 1.2px。強調は黒塗り白文字（例：`STREAK 6`）、補足は白地（例：読書 6日連続） |
| セクション見出し | 黒塗りタグ（`DAILY` `WEEKLY` `MONTHLY` など）＋日本語＋右に件数 |
| 上部タブ | 文字＋件数、選択中は太字＋黒の下線 2px |
| 主ボタン | 黒のピル型、白文字、高さ 48〜52 |
| 副ボタン | 白のピル型・黒枠 1.5px |
| テキストリンク | 太字＋下線 |
| 入力欄 | 黒枠 1.5px の四角、高さ 46。フォーカス中は 2.5px |
| 切り替え（セグメント） | 黒枠の横並び。選択中は黒塗り＋白のチェック |
| トグル | 44×26 のピル。ON＝黒地に黄色のつまみ、OFF＝白地に白のつまみ（黒枠） |
| 数字キー | 黒枠 1.5px の四角、高さ 40 |
| ボトムシート | 白・黒枠 1.5px、上辺のみ角丸 18、取っ手は黒 36×4。背景の暗幕は黒 45% |
| モーダル（日付選択） | 白・黒枠 1.5px・角丸0、幅 335。選択日は黒塗り、日付の下に草色の小さな四角 |
| 強調マーカー | 黄色の帯の上に太字（例：あと 10 回で目標） |
| 吹き出し | 白・黒枠 1.5px の四角、太字 11〜12 |

## 草（年間）

- 53週 × 7日のマス。マス間 1.2px。角丸なし。
- 月ラベル（1〜12）を上に。凡例「少 ■■■■ 多」とヒント「草をタップで、その月のカレンダーへ」を下に。
- 記録がない場合は全マス灰色、今日のマスだけ黄色（E3）。
